# Agent skills

Develop and operate agents on Hopsworks: served interactive agents and
scheduled agent tasks. The live, canonical list is `hops skills list --bucket agents`.

- [hops-agent-deployment](hops-agent-deployment/SKILL.md) — Deploy an interactive agent (e.g. LlamaIndex) as a served deployment.
- [hops-agent-task](hops-agent-task/SKILL.md) — Create, run and schedule an agent task: a coding agent (claude-code / codex) executing instructions as a job.
