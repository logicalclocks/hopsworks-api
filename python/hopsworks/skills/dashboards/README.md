# Dashboard skills

Streamlit, Gradio, Flask, Node.js and custom apps, and Superset dashboards over feature store data.
The live, canonical list is `hops skills list --bucket dashboards`.

- [hops-app](hops-app/SKILL.md) — Build and manage Python app deployments (Streamlit, Gradio, Flask, Node.js and custom apps).
- [hops-app-db](hops-app-db/SKILL.md) — Connect an app or agent to the project's data: the online database (`MYSQL_*`, secret, privileges) and the offline feature groups through Trino (`TRINO_*`); Python, SQL and Node.js (`@hopsworks/app`) examples.
- [hops-superset](hops-superset/SKILL.md) — Build Superset datasets, charts, and dashboards.
