# Dashboard skills

Streamlit / custom Python apps and Superset dashboards over feature store data.
The live, canonical list is `hops skills list --bucket dashboards`.

- [hops-app](hops-app/SKILL.md) — Build and manage Python app deployments (Streamlit + custom apps).
- [hops-app-db](hops-app-db/SKILL.md) — Connect an app or agent to the project database (`MYSQL_*` variables, secret, privileges); Python, SQL and Node.js examples.
- [hops-superset](hops-superset/SKILL.md) — Build Superset datasets, charts, and dashboards.
