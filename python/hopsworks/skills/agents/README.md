# Agent skills

Develop and operate agents on Hopsworks: served interactive agents, their
evaluation, and scheduled agent tasks. The live, canonical list is `hops skills list --bucket agents`.

- [hops-agent-deployment](hops-agent-deployment/SKILL.md) — Write an agent with `AgentApp` and deploy it as a served, chat-ready deployment; talk to it from Python.
- [hops-agent-evals](hops-agent-evals/SKILL.md) — Evaluate, monitor and improve a deployed agent: suites and checks, LLM judges on live traffic, traces and feedback, failure analysis into regression tests.
- [hops-agent-task](hops-agent-task/SKILL.md) — Create, run and schedule an agent task: a coding agent (claude-code / codex) executing instructions as a job.
