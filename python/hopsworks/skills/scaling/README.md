# Scaling skills

How served workloads scale on Hopsworks: model deployments and agent deployments
alike (both are KServe deployments with one scaling configuration per component).
The live, canonical list is `hops skills list --bucket scaling`.

- [hops-autoscaling](hops-autoscaling/SKILL.md) — Choose the deployment mode, the autoscaler and the scale metric, scale to zero when idle, and verify that a deployment scales.
